# Menuiserie Cortopassi

Site vitrine de la Menuiserie Cortopassi, artisan menuisier dans le Var. Le site présente les réalisations, les prestations et la zone d'intervention de l'atelier.

## Prérequis

- Node.js
- npm

## Développement

```bash
npm install
npm run dev
```

Astro affiche l'adresse locale dans le terminal.

## Vérification et aperçu de production

```bash
npm run build
npm run preview
```

Le site statique généré est placé dans `dist/`.

## Contenu

- `src/pages/` : pages du site
- `src/components/` : composants Astro
- `src/data/` : données du site et réalisations
- `public/images/` : logo, photos et autres ressources statiques

Les photos publiques sont servies directement depuis `public/`.
